The training arc

Your 32-week roadmap

Nine seasons. Each one ends with a boss you must actually defeat — a deployed project, not a finished playlist. Tick each topic as you go.

The nindō rule

“I never go back on my word. That's my ninja way.”

You will not feel motivated every day — Naruto didn't either. What carried him was a rule, not a mood. Yours: never skip two days in a row. Miss Monday? Fine. Tuesday is non-negotiable.

01
🎮 ACADEMY ARC · Week 1–2

Setup, Git & HTML/CSS Pro

⏱ 24h 0%

Lock your tools, master Git, and sharpen HTML/CSS until your UI looks hireable. You already know the basics — this arc turns them into proof.

🐲 Boss to defeat: A responsive 3-page portfolio site, deployed live, with 10+ GitHub commits and a real pull request.

Watch / read (verified links)

  • Complete Git and GitHub Tutorial ↗Kunal Kushwaha1h15m · English
  • HTML & CSS Full Course – Beginner to Pro ↗SuperSimpleDev6h30m · English
  • Frontend Roadmap (read, don't binge) ↗roadmap.sh30m · reference

💡 Rule: every day ends with a commit. A green GitHub square is your new high score.

02
⚡ CHAKRA CONTROL ARC · Week 3–7

JavaScript Deep Dive

⏱ 70h 0%

JavaScript is 80% of every full-stack interview. This is the arc where you stop copying code and start understanding it.

🐲 Boss to defeat: 3 vanilla JS apps deployed: Todo (localStorage), Weather (live API), Quiz (timer + score).

Watch / read (verified links)

  • JavaScript Tutorial Full Course – Beginner to Pro (2024) ↗SuperSimpleDev22h · English
  • Namaste JavaScript (Season 1 + 2) ↗Akshay SainiPlaylist · English
  • The Modern JavaScript Tutorial ↗javascript.infoReference · read daily

💡 Watch at 1.5×, then close the video and rebuild the feature from memory. If you can't, you didn't learn it yet.

03
🔥 POWER-UP ARC · Week 8–11

React + TypeScript + Tailwind

⏱ 80h 0%

Stop thinking in pages. Start thinking in components, state and props. TypeScript is now expected in Indian product-company JDs, not optional.

🐲 Boss to defeat: React + TypeScript 'Expense Tracker' with routing, charts, filters and persistence — deployed.

Watch / read (verified links)

  • Chai aur React ↗Hitesh Choudhary (chai aur code)~20h · Hindi/Hinglish
  • TypeScript playlist ↗Hitesh Choudhary~5h · Hindi/Hinglish
  • Learn React (official docs) ↗react.devReference · English
  • Tailwind CSS docs ↗tailwindcss.comReference

💡 Do not start Redux yet. Context + hooks is enough for fresher interviews. Depth beats checkbox collecting.

04
🏰 BACKEND DUNGEON ARC · Week 12–16

Node.js + Express + MongoDB

⏱ 90h 0%

Your first real API. Auth, validation, error handling, deployment — the exact things interviewers probe when they hear 'I know MERN'.

🐲 Boss to defeat: A production-style REST API (Job Board) with JWT auth, roles, pagination, docs and a Postman collection — deployed.

Watch / read (verified links)

  • Complete Backend Developer Course (chai aur backend) ↗Hitesh Choudhary~30h · Hindi/Hinglish
  • Node.js Crash Course Tutorial ↗The Net Ninja4h30m · English
  • MongoDB free courses ↗MongoDB UniversitySelf-paced · English

💡 If your API isn't deployed with a live URL in the README, most recruiters will never see it. Deploy in week 12, not week 16.

Halfway checkpoint · around day 110

“Go beyond. PLUS ULTRA!”

If the authenticated API is deployed, you are no longer “an intern who knows HTML”. You are a full-stack developer with a smaller portfolio. This is the exact point where most people quit — the second half is where the offers live.

05
🗺️ SIDE QUEST ARC · Week 17–18

SQL + Python (Kerala JD insurance)

⏱ 45h 0%

A large share of Kerala JDs ask for SQL or Python. You don't need to become a data scientist — you need to be dangerous enough to survive a technical round.

🐲 Boss to defeat: A 5-table SQL schema + 20 queries for your capstone, plus a small Python CLI and a 2-endpoint Flask/Django API.

Watch / read (verified links)

  • MySQL Tutorial for Beginners [Full Course] ↗Programming with Mosh3h10m · English
  • Python Tutorial – Python for Beginners ↗Programming with Mosh6h · English
  • Django official tutorial (or Flask quickstart) ↗Django docs3h · English

💡 Python tip: don't do a 40-hour data-science course. 15 focused hours + one working script beats 40 hours of videos.

06
🐉 FINAL BOSS ARC · Week 19–22

Capstone + Docker + CI/CD

⏱ 70h 0%

One full-stack product you can demo for 5 minutes without notes. This is the project that carries your resume, your interviews and your confidence.

🐲 Boss to defeat: 'SkillBridge' — a full-stack app (auth, roles, CRUD, dashboard) deployed live with Docker + GitHub Actions.

Watch / read (verified links)

  • Docker Tutorial for Beginners [FULL COURSE in 3 Hours] ↗TechWorld with Nana3h · English
  • GitHub Actions documentation ↗GitHub DocsReference
  • Deployment guides ↗Vercel / Render / RailwayReference

💡 Choose the alternate capstone if you want a data + full-stack story. It is memorable in interviews and it doubles as market research for your own job hunt.

07
🗡️ DSA DOJO (DAILY) · Week 3–32 · 45 min/day

DSA & Problem Solving

⏱ 40h 0%

Kerala service companies and product companies both screen with aptitude + coding rounds. Consistency beats marathon weekends.

🐲 Boss to defeat: 150 curated problems solved + 2 timed mock coding rounds.

Watch / read (verified links)

  • Striver's A2Z DSA Sheet & Course ↗takeUforward450 items · free
  • Striver A2Z playlist ↗takeUforwardYouTube playlist
  • NeetCode Roadmap (optional) ↗NeetCodeFree · English

💡 Track problems in the Excel sheet. If a problem takes >35 min, read the editorial, then re-solve it 3 days later from scratch.

08
📊 BONUS BOSS ARC · Week 23–24 (only after capstone)

Power BI + Analytics

⏱ 30h 0%

This is your differentiator, not your core. Kerala service companies and data-adjacent roles love a dev who can also build a dashboard.

🐲 Boss to defeat: A 2-page Power BI dashboard published online + a 5-line business insight write-up on your portfolio.

Watch / read (verified links)

  • Power BI Project for Beginners (Sales Insights) ↗codebasics3h · English
  • Power BI Data Analyst (PL-300) certification path ↗Microsoft LearnOptional · free path
  • DAX overview ↗Microsoft LearnReference

💡 Do not start this before Season 6. Power BI is a multiplier on a full-stack profile — it cannot replace one.

09
🏁 JOB HUNT ENDGAME · Week 25–32

Portfolio, Resume & Offers

⏱ 100h 0%

Job hunting is a numbers game with a quality filter. 300 targeted applications + 30 referrals + 12 mock interviews is the formula.

🐲 Boss to defeat: A signed offer. Your first CTC is not your final form — your learning curve is.

Watch / read (verified links)

  • System Design Primer ↗GitHub · donnemartinReference
  • Frontend interview questions ↗GeeksforGeeksReference
  • Career + interview videos (Malayalam) ↗Brototype MalayalamChannel · Malayalam

💡 A referral is worth 20 cold applications. Your current internship colleagues are referral gold — ask them before you leave.
